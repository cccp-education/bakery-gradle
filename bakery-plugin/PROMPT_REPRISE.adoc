== Leçon méthodologique (importante)

Le scope d'un lot **NE peut PAS** être un fichier via la tâche Gradle : le plugin
ktlint-gradle 12.2.0 ignore `include(...)`/`setSource(...)` (le `PatternFilterable`
est ré-écrasé). Prouvé : un run « scopé » a reformaté 63 fichiers de `src/test`
(S-231 bis), **revert immédiat**. 

*Outil correct pour un scope fichier* : le **CLI ktlint** (classpath résolu via une
configuration Gradle jetable `ktlint-cli:1.5.0`, cf. `/tmp/ktlint-cli-cp.txt` dans
la session). *Toujours vérifier `git status` juste après le premier run.*
