== Technique de pool de connexion Ollama (cross-borough)

Le pool de connexion est dans document-gradle (`PooledOllamaTranslationAdapter`) :
- Round-robin sur 29 ports 11437-11465 via `AtomicInteger`
- Chaque port = une instance Ollama Docker avec Device Key SSH ed25519 distincte
- Chaque Device Key = un compte Ollama Pro distinct (17€/mois annuel)
- Fallback : port échoue → suivant, tous épuisés → Failure
- Modèle : `gemma4:31b-cloud` (autorisé AGENTS.adoc)
- Ports 11434-11436 JAMAIS utilisés (comptes Google personnels)

Bakery-gradle consomme ce pool via `document.translation.ContentTranslationService`
(importé de document-gradle, câblé dans `MigrateContentI18nTask`).

== Réalité augmentée DocKnowledgeBase

`DocKnowledgeBase` (bakery.rag) injecte la doc officielle JBake dans le prompt de traduction :
- Keyword matching in-memory sur `resources/docs/jbake-reference.adoc`
- Le LLM reçoit "JBake reference (this content uses JBake templates and conventions):" + sections pertinentes
- Contrecarre la tendance du LLM à confondre les conventions JBake
