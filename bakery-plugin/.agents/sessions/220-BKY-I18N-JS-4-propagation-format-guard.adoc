== Décisions actées

. **Propagation = étape de la tâche de traduction** (pas une tâche séparée) —
   la tâche écrit la source de dev puis aligne la copie de publication, dans le
   même run. Le flag `propagate` (défaut `true`) permet un run traduction-only.
. **Écriture delta sur la copie de publication** : seules les copies driftées
   sont réécrites (Loi Économie d'Encre) — un arbre aligné est un no-op.
. **Dry-run = zéro écriture** sur les deux arbres (source + publication).
. **Garde de format câblée en production** (pas seulement en test) : un fichier
   invalide est écarté du plan et un résultat invalide n'est jamais écrit.
. **Frontière HTTP vérifiée par test d'architecture** : le domaine ne connaît
   aucune API réseau, cohérent avec le constat C-1 (socle LLM bakery local
   derrière le port N0).
