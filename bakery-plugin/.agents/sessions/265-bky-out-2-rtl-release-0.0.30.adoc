== BKY-OUT-2 — direction du document

* `bakery.i18n.DocumentDirection` (pur) : `RTL_LANGUAGES = ar/fa/ur`, `isRtl`,
  `apply(header, language)` pose `dir="rtl"` sur la balise `<html>`, **retire** un
  `rtl` hérité pour une langue LTR, conserve la forme auto-fermante, idempotent.
* `localizeSeoHead` localise désormais **tout le head** en une passe (champs SEO
  + direction) — un seul task à câbler, pas deux.
* Tests : 8 UT + 2 FT TestKit + 2 scénarios BDD (shard `LangSwitchEcosystem`,
  58/58 verts).
* Dogfooding cheroliv.com : `ar`/`fa`/`ur` portent `dir="rtl"`, `de`/`en` intacts ;
  les 4 espacements physiques de `styles.css` passés en logique
  (`margin-inline-end`, `padding-inline-start`) côté site.
