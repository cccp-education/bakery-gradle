== Mission

EPIC transverse **GBL-010**, branche A, **G-1** : bakery possède la **branche
Template** (jbake/Thymeleaf, les pages). Pour chaque `template × langue`, il doit
exposer un **statut** (`MISSING`/`UNTRANSLATED`/`TRANSLATED`) — le nœud
`templates` de l'arbre unifié (G-4). `VariantDeployability` ne connaissait que la
moitié *missing* ; l'audit complète la vue (le statut byte-identique = piège copy-FR
S-043/S-044).

Vision pilote : *« une branche pour le template jbake, l'autre pour la data. »*

== Livrable — domaine pur `bakery.tree.TemplateTreeAudit`

* `TemplateTranslationStatus` (`MISSING`/`UNTRANSLATED`/`TRANSLATED`),
  `TemplateNode(language, template, status)`, `TemplateTree` (`unconverged`,
  `isConverged`, `forLanguage`, `count`, `render()` **déterministe**).
* `TemplateTreeAudit.of(referenceTemplates, variantTemplates, referenceLanguage)`
  — liste les templates de référence (`.thyme`/`.ftl`/`.html`, miroir de
  `VariantDeployability`), puis pour chaque langue : `MISSING` (absent),
  `UNTRANSLATED` (byte-identique au référence), `TRANSLATED` (diffère). Générique :
  le layout est fourni par l'appelant (aucune hypothèse site).

== Preuve réelle (corpus cheroliv.com, hors test)

[source]
----
en : total=19 untranslated(byte-identical)=0 missing=0
de : total=19 untranslated(byte-identical)=1 missing=0   ← résidu copy-FR détecté
ru : total=19 untranslated(byte-identical)=0 missing=0
----

La règle byte-identique (UNTRANSLATED) attrape le template `de` resté au français —
invisible à `VariantDeployability` (qui ne voit que *missing*).
