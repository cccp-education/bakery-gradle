== Livré — BKY-LANG-NAV-2

=== 1. `LangSwitchPath.thymeleafHref` — règle symbolique (DDD)

`LangSwitchPath` enrichi de son **frère symbolique** : `resolveSamePage` est la
règle *concrète* (prend une URI de page), `thymeleafHref` en est la projection
*symbolique* — un `th:href` exprimé en `${content.rootpath}` / `${content.uri}`,
évalué **par page au bake**.

Contrainte de conception : `injectLangSwitch` injecte dans `menu.thyme`, un
template **partagé par toutes les pages** d'une langue. Aucune « page courante »
n'existe à l'injection — le lien doit donc être une *expression* évaluée au
rendu. D'où le choix symbolique plutôt que la valeur concrète.

[source,kotlin]
----
fun thymeleafHref(currentLang, targetLang, defaultLang): String
----

Quatre cas :
. self-link → `${content.uri.substring(content.uri.lastIndexOf('/') + 1)}`
   (nom de fichier seul, pas de relance de navigation) ;
. défaut → langue non-défaut → `${content.rootpath + 'en/' + content.uri}` ;
. non-défaut → défaut → `|../${content.rootpath}${content.uri}|` (sort de l'arbre
   de langue puis rejoue la page) ;
. non-défaut → non-défaut → `|../${content.rootpath}ar/${content.uri}|`.

Note technique : Thymeleaf 3.0.14 **ne dispose pas** de `#strings.substringAfterLast`
(sources vérifiées) → expression OGNL `content.uri.substring(...)` retenue et
**prouvée par évaluation réelle** dans le TemplateEngine.
