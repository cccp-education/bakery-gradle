== Cause racine

La boucle `sourceFile.copyTo(targetFile, overwrite = true)` copiait la source
vers la cible AVANT la traduction bloc-delta. Au 2e run, `translateSingleFileWithBlockDelta`
parsait le fichier source (sans `[EN]`) comme « précédents blocs traduits » →
blocs préservés = texte source. Viol de la Loi Économie d'Encre.

== Correctif

Déplacement de la copy loop dans la branche `translationService == null` (chemin
legacy sans LLM). Le `translateSingleFileWithBlockDelta` écrit lui-même `targetFile`
dans la branche LLM.
