=== REFACTOR (fix fixtures tests, production inchangée)
4 tests échouaient en GREEN car mes fixtures initiales encodaient une attente
erronée de la sémantique diff (drift de valeur → Update au lieu de Create +
Delete) :
- `DnsDiffTest$Combined` — le cas Update était construit sur un drift de
  valeur ; remplacé par un drift de TTL (valeur identique, TTL 7200) + ajout
  d'un record manquant pour obtenir le Create (Create=1, Update=1, Delete=1)
- `DnsProvisionerTest$Apply` — « updates drifted record keeping id » : fixture
  CNAME à valeur différente → ClassCastException Create→Update ; mis à drift de
  TTL (même valeur, TTL 7200) → Update(id=5) conforme
- `DnsProvisionerTest$Apply` — « no refresh when nothing applied » : désiré a1
  absent de la zone → Create appliqué ; ajout `ExistingDnsRecord(1L, a1)` pour
  que seul l'orphan TXT reste (skipped, no purge → rien appliqué, pas de
  refresh)
- `NoOpDnsProviderTest` — « reconcile is safe » : avec dryRun=false la zone
  vide NoOp → Create « appliqué » ; passé à dryRun=true (défaut) → applied vide,
  skipped=1
Sémantique assumée et documentée : **drift de valeur = Create + Delete** (pas
Update en place), alignée sur ovh.py et le multi-valeurs apex GitHub Pages.

== Décisions

- Sémantique diff par **slot (type, name)** + **jeu de valeurs** (le apex porte
  plusieurs A distincts — GitHub Pages round-robin) : value-set decide
  create/update/delete ; drift de valeur = Create + Delete (jamais Update en
  place), drift de TTL sur valeur identique = Update (garde l'id)
- Port `DnsProvider` (pattern capsule) + `OvhDnsProvider` (délégation fine à
  `OvhDnsClient`) + `NoOpDnsProvider` (dégradé, zone vide, mutations no-op) +
  factory `DnsProviderFactory.resolve` (pattern `resolve*Provider` capsule)
- `DnsProvisioner.reconcile(desired, dryRun=true, allowDelete=false)` :
  dry-run par défaut (défaut DnsConfig) ; delete seulement avec le flag de
  purge (note backlog « delete must require a double flag ») ; `noop` si plan
  vide ; refresh zone seulement si applied non vide (économie d'encre)
- `RecordingProvider` en test (mémoire, mutable) pour rejouer la
  réconciliation et prouver l'idempotence
