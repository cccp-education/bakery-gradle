== Actions Entreprises

=== 1. MASS-1 — `BlockChecksum` + `BlockDelta` (DDD pur) ✅

*document-gradle* — `document/translation/delta/` :

* `BlockChecksum.kt` :
  * `BlockTranslationStatus` enum (`TRANSLATED`, `PENDING`)
  * `BlockChecksumEntry(hash, status)` — `parse("hash:STATUS")` +
    `serialize()`. Legacy `"hash"` seul → statut `PENDING` (rétro-compatible).
  * `BlockChecksum.sha256(block)` SHA-256 par bloc translatable + `computeForBlocks(blocks)`
    → `Map<idx, hash>` (heading, paragraph, list, table, admonition, source,
    descriptionList). `Hr`/`BlockMacro` non-checksummés.
* `BlockDelta.kt` : `BlockDelta(modifiedBlocks, preservedBlocks)` value object pur.
  `compute(previous: Map<String,BlockChecksumEntry>, current: Map<String,String>)` :
  un bloc est *modifié* si absent / hash différent / statut ≠ `TRANSLATED`, sinon *préservé*.
  Cas critique couvert : un diagramme `[plantuml]` traduit dont le texte environnant
  change n'est PAS re-traduit (checksum du bloc diagramme inchangé + statut `TRANSLATED`).

* Tests : `BlockDeltaTest.kt` (26 UT verts, dont `parse` round-trip, statut `PENDING`,
  format legacy), `DocumentTranslatorBlockDeltaTest.kt` (4 UT), `BlockDeltaWireDebugTest.kt` (1).

== Issue 191-1 (À FIXER — S192)

*FT rouge* : `second run with one modified block preserves other blocks` échoue sur
`afterSecond.contains("Second paragraph. [EN]")`.

*Diagnostic établi* : le bloc « Second paragraph » (préservé) est réécrit en texte source
SANS `[EN]`. *Cause racine confirmée* : **`MigrateContentI18nTask` ligne 124-129** — la
boucle `for (relPath in filesToTranslate) { ... sourceFile.copyTo(targetFile, overwrite = true) }`
**copie la source vers la cible AVANT la traduction bloc-delta**, écrasant le fichier
traduit précédent avec le texte source. Au 2e run, `translateSingleFileWithBlockDelta`
parse alors le fichier source (sans `[EN]`) comme « précédents blocs traduits » → les blocs
préservés héritent du texte source.

*Pourquoi les autres tests passent* :
* fresh : fichier cible inexistant au départ, la copie ne détruit rien de traduit ;
* idempotence : `filesToTranslate` vide (delta fichier vide) → la boucle ne copie rien ;
* `debug exact task flow` : appelle `ContentTranslationService` directement, sans la boucle de copie.

*Correctif prévu S192* :
. Supprimer / conditionner la boucle de copie (lignes 124-129) — ne copier vers la cible
  que dans le branche `translationService == null` (chemin legacy sans LLM). Le
  `translateSingleFileWithBlockDelta` écrit lui-même `targetFile`.
. Vérifier aussi que la boucle de traduction ne repose plus sur la copie préalable.
. Nettoyer les `println` de debug : `[block-delta]` dans `ContentTranslationService.translateSingleFileWithBlockDelta`,
  `[task] target exists before:` dans `MigrateContentI18nTask`, `DEBUG`/`println` dans
  `MigrateContentI18nDeltaFunctionalTest` et `BlockDeltaWireDebugTest`.
