== Livré — BKY-LANG-NAV-1

=== 1. `LangSwitchPath` — objet pur (no I/O)

`src/main/kotlin/bakery/langswitch/LangSwitchPath.kt` : l'**unique** source de
vérité de la règle. Signature :

[source,kotlin]
----
fun resolveSamePage(
    currentPageUri: String,
    currentLang: String,
    targetLang: String,
    defaultLang: String,
    pageExists: (String) -> Boolean = { true },
): String
----

Modèle d'arbre : la langue défaut vit à la racine (`blog/foo.html`), les autres
sous leur répertoire (`en/blog/foo.html`). Le retour est une URL **relative
exprimée depuis le répertoire de la page courante** — elle fonctionne telle
quelle dans le document rendu.

Algorithme :
. normalisation (trim + `trimStart('/')`) ;
. self-link → nom de fichier seul (`foo.html`) ; un self-link ne relance jamais
   la navigation ;
. retrait du préfixe de langue courante (si non-défaut) ;
. chemin absolu de la cible sous la langue cible, avec **dégradation** vers
   `<lang>/index.html` si `pageExists` retourne `false` (D8) ;
. relativisation depuis le répertoire courant (`../../blog/foo.html`).
