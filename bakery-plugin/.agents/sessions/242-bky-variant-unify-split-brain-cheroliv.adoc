=== La divergence de comportement (prouvée)

`bakery` filtre `file.isFile && extension in {thyme, ftl, html}`. `cheroliv`
comparait **toutes** les entrées (`referenceTemplates.listFiles().map { it.name }`).
Conséquence : un bundle `messages_{lang}.properties`, un `.txt` ou un **dossier**
(`jbake/templates/TODO/`, présent dans la référence + 18 variantes du site réel)
était traité comme un template exigé → une variante complète pouvait être
**faussement déclarée indéployable** et exclue silencieusement du bake.
