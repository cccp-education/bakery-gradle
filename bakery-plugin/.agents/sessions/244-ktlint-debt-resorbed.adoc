== Découverte méthodologique — le lot NE PEUT PAS être un fichier

La tentative naturelle — scoper `runKtlintFormatOver*` par `include(...)` ou
`setSource(files(...))` via init-script — a été **prouvée inopérante** : le plugin
ktlint-gradle (12.2.0) ré-applique sa `source` FileCollection, ignorant le
`PatternFilterable` de la tâche. La preuve : un run « scopé » sur un fichier sonde
a reformaté **63 fichiers de `src/test`**. C'est *exactement* le mode d'échec S-231.

*Revert immédiat* (`git checkout -- src/`), puis recherche du bon outil.

*Solution retenue* : le **CLI ktlint 1.5.0** (`com.pinterest.ktlint.Main`), dont le
classpath a été résolu une fois via une configuration Gradle jetable
(`ktlint-cli:1.5.0`). Le CLI accepte des *chemins de fichiers explicites* → scope
au fichier près, zéro effet de bord.

*Lot effectif retenu* : le **source set** (la seule frontière fiable côté tâche
Gradle), ou le fichier via le CLI pour les corrections manuelles.

=== Bug découvert au lot 1 — garde fragile

Le reformatage de `build.gradle.kts` a fait passer `BakeryPluginPublicationTest`
**RED** : la garde parsait le script **ligne à ligne**
(`lineSequence().first { it.startsWith("version =") }.contains(...)`), or ktlint
découpe désormais `version = ws.versions.bakery.plugin.get()` sur 3 lignes
(`chain-method-continuation`). Même famille que F34 (S-243, proxy `th:text=`) :
une assertion couplée à la **forme** du source plutôt qu'à son contenu.

Correctif : garde **whitespace-insensitive** (`buildScript.withoutWhitespace()`,
assertion sur `version=ws.versions.bakery.plugin.get()`), RED → GREEN prouvé.
Le lot 1 a été **reconstruit** pour inclure le correctif (chaque commit reste vert).

== Leçons

. *Un filtre de tâche Gradle peut être ignoré en silence* : ne jamais supposer
  qu'`include(...)` scope la tâche ; **vérifier le périmètre effectif** (`git status`)
  immédiatement après le premier run. C'est la vérification qui a attrapé S-231 bis.
. *Le CLI ktlint résolu par Gradle* est l'outil de scope fichier : classpath
  résolu via une configuration jetable, jamais de bricolage de tâche.
. *Une garde qui parse la forme du source est un bug dormant* : F34 (S-243) puis
  lot 1 (S-244) — deux occurrences. Toute assertion textuelle doit être
  whitespace-insensitive.
. *La résorption par lots tient la dette décroissante* : 171 → 170 → 111 → 102 →
  38 → 36 → 5 → **0**, chaque valeur prouvée par `ktlintGenerateBaseline`.
