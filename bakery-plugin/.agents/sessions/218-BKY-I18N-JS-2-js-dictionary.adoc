== Livrable (baby-step DDD/TDD strict)

=== Domaine pur

`src/main/kotlin/bakery/i18n/js/I18nJsDictionary.kt` — object pur, zéro I/O, zéro Gradle,
zéro LLM. Miroir exact du harness `tools/translate-i18n.mjs` (S-044) :

* `parse(vararg sources)` — fusionne plusieurs sources (chrome + patch), ordre
  d'insertion préservé (LinkedHashMap, déterministe).
* `languagesOf(source)` — codes de langue en ordre de document.
* `insertTranslations(source, language, translations)` — n'ajoute que les clés
  **manquantes** (Loi Économie d'Encre), préserve le document alentour
  byte-identique, idempotent.

*Deux invariants de parsing supérieurs au harness node* :

. **Scanner de braces string-aware** : `{` / `}` dans un littéral double-quote
  (échappé ou non) sont ignorés → une valeur `"{0}"` ne tronque jamais un bloc.
  Le harness naïf `matchingBody` comptait tous les braces.
. **Regex de bloc ancrée `^\s{4}[a-z]{2}: \{`** (miroir harness) : les entrées
  quotées hors bloc (ex. `var OUTSIDE = { "nav.home": ... }`) sont ignorées.

=== Bugs attrapés par le TDD

* **Escape `\n` perdu** : `String.replace(Regex, "\\n")` en Kotlin passe par
  `Matcher.replaceAll` — `\n` y est un échappement de groupe et perdait le
  backslash, écrivant `nligne2` au lieu de `\nligne2`. Fix : lambda de remplacement
  `{ "\\n" }`. Attrapé par `inserted values escape quotes and newlines`.
