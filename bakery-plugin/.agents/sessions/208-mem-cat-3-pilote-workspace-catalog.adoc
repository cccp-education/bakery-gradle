== Ce qui a été fait

=== Fix-0 — Déblocage baseline

Le build racine bakery était ROUGE : Gradle 9.6.1 épingle le Kotlin embarqué
(`kotlin-stdlib {strictly 2.3.21}`, `annotations {strictly 13.0}`) sur le
classpath buildscript, en conflit avec les constraints platform workspace-bom
(2.4.10 / 26.0.2-1) tirées transitivement via `bakery-plugin → document-plugin
→ plantuml-plugin → workspace-bom`.

Fix : block `buildscript { configurations.all { resolutionStrategy.force(...) } }`
dans `build.gradle.kts` racine (pattern readme-plugin / CNV-12.2 conventions).
Runner-gradle (2e consommateur bakery) fixé identiquement côté MEMPHIS.
