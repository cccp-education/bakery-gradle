== Leçons

- **YAML generation in steps** : `trimIndent`/`trimMargin` produisent des indentations incohérentes quand on concatène des blocs séparés. Préférer `StringBuilder` ligne par ligne pour les YAML générés dans les steps Cucumber.
- **Cucumber `{string}` vs literals** : les steps avec `{string}` nécessitent des guillemets dans la feature ; les steps avec `{word}` matchent un seul token sans espaces. Les `.` dans les valeurs littérales (ex `sitemap.xml`) cassent le matching → utiliser `{string}` + guillemets.
