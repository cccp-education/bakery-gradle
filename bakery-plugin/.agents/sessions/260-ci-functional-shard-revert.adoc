== Leçons

1. **Mesurer, ne pas déduire.** Un modèle `wall = k × somme` calibré sur un run
   unique est invalide : la variance inter-runs par classe atteint ×5.
2. **La contention des builds GradleTestKit imbriqués est pairwise.** Déplacer des
   classes peut *créer* un bin pathologique (ici `functional-shard-A`).
3. Un revert propre est un livrable : il préserve la partition validée et documente
   l'impasse, évitant qu'une session future ne retente le même rééquilibrage.
