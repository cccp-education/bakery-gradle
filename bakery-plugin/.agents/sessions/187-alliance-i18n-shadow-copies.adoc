== Contexte

Les 5 fichiers `contracts/i18n/` dans `src/main/kotlin/` étaient des copies
identiques (octet pour octet) des contrats N0 du BOM `i18n-contracts:0.0.2`.

déjà dans `build.gradle.kts` — les shadow copies étaient redondantes et
créaient un risque de divergence.
