== Diagnostic de cadrage

Le cadrage S-228 définit NAV-5 comme « fixture FR+EN multi-pages → bake →
assert : `en/blog/foo.html` garde `data-lang`, lien FR = `../blog/foo.html`,
pas d'accueil, pas de self-loop, langue active ». Deux exigences de méthode :

. **Couvrir les deux hôtes** (D3) — la feature doit faire passer la *même*
   page par l'hôte **injecté** (`injectLangSwitch` : `LangSwitchMenu` →
   `LangSwitchThymeleafRenderer` → `LangSwitchInjector`, chaîne de production
   réelle) **et** par l'hôte **modèle** (`site-basic/templates/menu.thyme`,
   sélecteur `th:each`), puis exiger leur **accord** mutuel et l'accord avec
   `LangSwitchPath.resolveSamePage`.
. **Ne pas dépendre d'un serveur** — le cadrage S-228 avait acté que la tâche
   `bake` est testable sans serveur. L'évaluation Thymeleaf par page est le
   niveau de preuve pertinent (le rendu est déterministe) ; un bake complet
   aurait ajouté une dépendance JBake lourde sans prouver davantage la règle.

Le modèle de page retenu est celui de la production : FR à la racine du site,
EN sous `en/`, donc `content.uri` = chemin de la page **dans** l'arbre de langue
et `content.rootpath` remonte à la racine de cet arbre — exactement l'hypothèse
de l'expression NAV-2 (documentée S-230, vérifiée S-232).

== Livré — BKY-LANG-NAV-5

=== 1. Feature `66_same_page_language_switch.feature` (6 scénarios)

Tag `@same-page`. Couvre les deux hôtes et leurs invariants :

* **FR → EN page imbriquée** : le lien EN = `../en/blog/foo.html`, pas l'accueil.
* **EN → FR page imbriquée** : le lien FR = `../../blog/foo.html`, pas l'accueil.
* **No self-loop** : le lien self EN = `foo.html` (nom de fichier seul) + classe
   `active` sur la langue courante.
* **Tous les liens contre la règle partagée** : chaque `data-lang` de chaque
   arbre == `LangSwitchPath.resolveSamePage(page, current, target, default)`.
* **Hôte modèle ex-nihilo** : `site-basic/templates/menu.thyme` résout
   `en/blog/foo.html` (EN) → FR en `../../blog/foo.html` et
   `blog/foo.html` (FR) → EN en `../en/blog/foo.html`, == règle partagée.
* **Accord des deux hôtes** : pour chaque langue, href injecté == href modèle.

=== 2. `SamePageLanguageSwitchSteps` (glue)

Fixture temporaire à deux arbres (FR racine + EN sous `en/`), menu à conteneur
`lang-switcher-container` vide. L'injection passe par la **chaîne de production**
exacte, puis chaque hôte est **rendu par le `TemplateEngine` réel** pour une page
donnée (contexte `content.uri`/`content.rootpath` calculé depuis l'URI du modèle
de page) et les ancres sont extraites par `data-lang`. La comparaison se fait
contre `LangSwitchPath.resolveSamePage` — la preuve anti split-brain D3 est
désormais **exécutable bout en bout**, pas seulement par vecteurs.

=== 3. `SamePageCucumberTestRunner` (pattern S-082)

Runner dédié tag `@same-page` (le runner principal resterait vert en silence si
la feature régressait). Imports explicites (pas de wildcard) — ktlint clean.
