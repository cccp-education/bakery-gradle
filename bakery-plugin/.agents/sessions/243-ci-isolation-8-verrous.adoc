== Décision / suite

* **CI bakery verte** — première fois depuis ≥ 2026-06-14 (run `36314219098`,
  `success`). Le hook de fin de session peut désormais citer une gate `build`
  réelle, et la CI est un filet de sécurité effectif.
* *Bug produit corrigé* : `GitService` honorait la branche déclarée **seulement**
  sur un dépôt neuf (`Git.init`), jamais après le `cloneAndOverlay` d'un remote —
  le push partait sur `master` au lieu de `main`. `ensureHeadOnBranch` le
  garantit désormais, prouvé par un UT TDD.
* *Hors périmètre (EPICs séparés)* : résorption dette ktlint (171 fichiers) ;
  correction racine du chemin kover dans `conventions-gradle` ; sémantique F50
  cross-borough document-gradle.
* *Leçon* : une CI morte en configuration **masque** l'ensemble de la dette
  aval. Débloquer la *première* étape révèle les suivantes en cascade — ici
  **13 verrous**, dont 1 vrai bug produit et 3 déterminismes d'environnement
  (`.editorconfig`, `XDG_CONFIG_HOME`, timezone) tous dus à des fichiers lus
  **hors du dépôt**. La parade systématique : **rendre le dépôt auto-suffisant**
  (tout ce qui influence un test doit être versionné dans le repo).
* Baby-step DDD/TDD/BDD strict : 1 fichier à la fois, RED → GREEN → REFACTOR,
  gate `test` complète. Zéro LLM, zéro secret, zéro traduction.
