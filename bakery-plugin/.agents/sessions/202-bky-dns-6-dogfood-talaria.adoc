== Approche

2. **GREEN (drift découvert)** — le test a échoué en révélant **2 bugs de

3. **FIX DnsDiff** — 2 correctifs + tests unitaires :
   - `DnsDiff.compute` : le delete ne concerne que les slots `(type, name)`
     présents dans le desired. Les records hors-scope sont laissés intacts.
   - `DnsDiff.compute` : `actual.ttl == 0` n'est pas un drift (zone default
     OVH). Update seulement si `actual.ttl != desired.ttl && actual.ttl != 0`.
4. **Re-run dogfood** — `noop=true`, `plan=0`, `applied=0`, `skipped=0`.
   Idempotence prouvée (2nd run = même résultat). BUILD SUCCESSFUL.

== Bugs corrigés (découverts par le dogfooding)

=== Bug 1 — Scoped orphan cleanup

*Avant* : `DnsDiff` parcourait tous les slots de `actualBySlot` et marquait
`Delete` pour tout record dont la valeur n'était pas dans le desired — y
compris les slots jamais déclarés dans le desired (NS, MX, SPF, CNAME ftp).

*Après* : `DnsDiff` ne marque `Delete` que pour les slots présents dans
`desiredBySlot` (`if (slot !in desiredBySlot) continue`). Les records
hors-scope sont laissés intacts — le provisioner ne gère que les slots
qu'il déclare.

*Test* : `out-of-scope records (NS, MX, SPF, ftp CNAME) are never deleted`.

=== Bug 2 — TTL=0 zone default

*Avant* : `actual.ttl != d.ttl` marquait un `Update` dès que les TTL
différaient, y compris quand `actual.ttl == 0` (convention OVH "zone
default").

*Après* : `actual.ttl != d.ttl && actual.ttl != 0` — le TTL `0` est
considéré comme "hérite de la zone" et n'est pas un drift.

*Test* : `a live ttl of 0 (zone default) is not a drift`.
