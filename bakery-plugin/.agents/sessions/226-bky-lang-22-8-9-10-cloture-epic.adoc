== BKY-LANG-22-9 — Dogfooding capsule vidéo 22 langues

=== Bug P0 découvert par le dogfooding réel (chaîne slider→capsule cassée)

Le dogfooding **réel** (pas les tests NoOp) a exposé une cassure de bout en
bout : la chaîne réelle slider `translateDeck` produit
`<slug>_<lang>-deck.adoc` ; `extractSpeakerNotes` dérive le script du nom de
fichier `.adoc` sans extension → il écrit `<slug>_<lang>-deck-script.txt` (le
suffixe `-deck` survit). Or `CapsuleVideoPlanner` cherchait exactement
`<deckName>_<lang>-script.txt` → **aucune paire trouvée**, fail-fast
`no matching deck + script pair`. La S-082 contournait par un `mv` manuel
documenté, jamais corrigé dans le code.

=== Fix baby-step DDD/TDD/BDD

- **DOMAINE** `CapsuleVideoPlanner.resolveScript(scriptDir, deckName, code)` :
  préfère `<deckName>_<code>-script.txt` (exact), tolère
  `<deckName>_<code>-deck-script.txt` (chaîne réelle), `null` si aucun.
  Miroir, côté entrée, du fix S-082 qui alignait déjà le WebM de sortie.
- **TDD** `CapsuleVideoPlannerTest` : 2 UT ajoutés. RED prouvé
  (`plan discovers real slider-generated scripts carrying the -deck suffix`
  FAILED avant le fix) → GREEN.
- **BDD** `multi_language_capsule.feature` : scénario
  « The real slider-to-capsule chain script carries a -deck suffix and is still
  resolved » + step `the plan entry for {string} resolves the script file {string}`.
  **14/14 PASSED**.

=== Dogfooding réel 22 langues (preuve)

Consumer composite `/tmp/opencode/dogfood-multilang22` (slider 0.0.19 + capsule
0.0.1 mavenLocal). Contournement environnemental documenté : le rendu
`asciidoctorRevealJs` Gradle est cassé par un conflit de gems JRuby
(`jar-dependencies 0.5.4 vs 0.4.1`, préexistant S-023/S-034) → HTML généré via
le Ruby système (`gem install asciidoctor asciidoctor-revealjs`), ce qui est
orthogonal au périmètre testé (TTS + capture).

Pipeline réel exécuté :

. `translateDeck` (corpus LANG-22-8 réutilisé, Économie d'Encre) → 63 adoc.
. `asciidoctor` (Ruby système) → 22 decks HTML (21 depuis source fr + 1 en→fr).
. `extractSpeakerNotes` → 67 scripts (dont les `-deck-script.txt` réels).
. `generateCapsuleVideoAllLanguages --rerun-tasks` → **21/22 rendered + 1
   skipped** (Économie d'Encre, WebM en→fr déjà valide) = **22 vidéos WebM**.

Résultat : **22/22 vidéos réelles** (espeak TTS + Playwright Chromium), durées
26 s → 81 s. Dégradation propre validée sur 3 voix espeak absentes en local
(`th`, `ja`, `ar` — `Failed to read voice`) : vidéo silencieuse produite
(26 s), pipeline continue (0 stream audio), zéro crash. Le fix planner est la
condition sine qua non : sans lui, `no matching deck + script pair found`.

Le répertoire `capsules/` étant gitignoré, seuls le fix + les tests sont
versionnés (les artefacts vidéo du dogfooding ne le sont pas — correct).
