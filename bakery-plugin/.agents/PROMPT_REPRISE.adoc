== Vision (GBL-010)

La traduction d'un site est un **arbre à deux branches** : **A Templates**
(`translateTemplates`, chrome natif) et **B Data** (articles → document → AST →
feuille `[plantuml]`). bakery possède la branche A et l'orchestration de la
branche B (`MigrateContentI18nTask` + `I18nDeltaApplier` + `PendingBlockRetry` +
`SubtreeI18nPlanner`). Un nœud, un propriétaire, un **statut** ; reprise en
**économie d'encre**. Cadrage racine : `CADRAGE_EPIC_GBL_010_ARBRE_TRADUCTION_SITE.adoc`.
