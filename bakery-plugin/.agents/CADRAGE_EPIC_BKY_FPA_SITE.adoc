== Constats

1. Le livre FPA navigable est DÉJÀ produit côté document-gradle (S-082 :
   livre.html/pdf/epub + TOC 116 sections). Bakery n'ajoute de la valeur
   QUE si le site JBake apporte navigation multi-pages, recherche ou
   indexation SEO — sinon Économie d'Encre = CADUQUE.
2. La chaîne GBL-003 vise d'abord le contexte augmenté des agents (RAG),
   pas le site public. Le site est un livrable secondaire (1 pt, optionnel).
3. Boundary bakery : génère/déploie un site à partir d'un corpus — le
   corpus FPA reste dans office/ (œuvre dérivée). Un site FPA public
   serait un dérivé CC BY-NC à arbitrer par le pilote (le livre est
   scanné, œuvre dérivée — la publication publique requiert un arbitrage
   licence explicite, PAS une décision technique).
4. La machinerie i18n bakery (BKY-I18N TERMINÉ, 10 langues) serait
   applicable si le pilote décide la publication publique — hors scope
   technique de cet EPIC.
